# Nettside

Statisk nettside (HTML + CSS) publisert med GitHub Pages.

## Filer

- `index.html` – hele nettsiden (én side)
- `styles.css` – design og layout

## Endre innhold

Alt innhold står i `index.html`. Åpne filen i en teksteditor (eller direkte på GitHub),
søk opp teksten du vil endre, lagre og last opp på nytt.
Prisene ligger i blokker som starter med `<div class="price-table">`.

Siden oppdateres automatisk et par minutter etter at endringer er pushet til `main`.
